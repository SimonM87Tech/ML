# Roadmap

Each phase = one or more missions + the guides they force you to read. Don't skip phases; each mission assumes the vocabulary of the previous one.

## Phase 1 — Tabular ML (the money skill)
Most companies that "need AI" actually need a model over a spreadsheet/database. This phase makes you dangerous on 70% of real client problems.
- [ ] Read `00-foundations/GUIDE.md`
- [ ] **Mission 01 — Customer Churn** (`missions/mission-01-churn/`)
- Guides unlocked: `01-classical-ml`

## Phase 2 — Deep learning + vision
Upgrade your old cats-vs-dogs project into modern practice: PyTorch, transfer learning, proper evaluation.
- [ ] **Mission 02 — Pet Breed Classifier, 37 classes** (`missions/mission-02-pet-breeds/`)
- Guides unlocked: `02-deep-learning`, `03-computer-vision`

## Phase 3 — Text
Fine-tune a small transformer; understand when fine-tuning beats calling an LLM API (a question every client will ask you).
- [ ] Mission 03 — to be defined after Phase 2 (candidate: support-ticket classifier)
- Guides unlocked: `04-nlp`

## Phase 4 — Time series
Forecasting demand/revenue/load. Common in FinTech and ops-heavy clients.
- [ ] Mission 04 — to be defined (candidate: store sales forecasting)
- Guides unlocked: `05-time-series`

## Phase 5 — Production
Take one earlier mission's model and serve it behind an API with monitoring. This is what separates "did a course" from "can deliver."
- [ ] Mission 05 — deploy the churn model
- Guides unlocked: `06-mlops`

## Ongoing — Advisory
Read `07-advisory/GUIDE.md` after Phase 1 and again after Phase 5. It will read differently each time.

## Rule of thumb for pace
A mission is done when you can explain every stage to a non-technical client in two sentences each, without notes.
